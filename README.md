# Discover-Turkey-Website
Turkey Travel Website is a multi-page frontend project built using HTML and CSS. The website presents Turkey as a travel destination by highlighting its history, culture, cuisine, famous attractions, and practical travel tips.

## Features
- Multi-page website structure
- Navigation bar linking Home, Culture & Food, and Attractions pages
- Informational travel content about Turkey
- Sidebar sections for quick facts, fun discoveries, and travel tips
- Image-based attraction cards
- Culture and cuisine section with supporting visuals
- Clean page layout using HTML and CSS

## Technologies Used
- HTML
- CSS
